## 2. Environment and splits

- Default `EnvConfig` (see `uavbench/env.py`). Any non-default config is a separate,
  named experiment.
- **Training layouts:** generated by the run seed via SB3 (`make_vec_env(seed=s)`).
- **Validation layouts:** reset seeds 20000+i (`--split val`). All tuning happens here.
- **Test layouts:** reset seeds 10000+i (`--split test`), n = 20. Used only for final runs.

## 3. Metrics

- **Primary:** `final_cov`, mean coverage over the last `FINAL_WINDOW` = 10 steps,
  averaged over test layouts.
- **Secondary:** `avg_cov` (whole-episode mean coverage, which also rewards fast deployment),
  training wall-clock time, planning time for baselines.
- Coverage = fraction of users whose best-UAV mean Al-Hourani path loss ≤ `pl_max`.

## 4. Statistical reporting

- **≥ 10 seeds** per method × regime (training seeds 0–9; baselines use the seed for
  their own randomness).
- Aggregate with `scripts/aggregate.py`: **IQM and mean with 95% stratified bootstrap CIs**
  (5000 reps, rliable). Each test layout is treated as a task; runs are resampled within tasks.
- Report **all** runs. No dropping "failed" seeds. If a run crashes, re-run with the same
  seed and log it.
- Claims of "A beats B" require non-overlapping 95% CIs on the primary metric, or an
  explicit probability-of-improvement estimate (rliable). Otherwise say "no clear difference."
- Plot training curves separately from evaluation scores.

## 5. Tuning protocol

- **Budget:** `__` trials per method (same for every method that has tunable settings,
  including PSO swarm size/iterations and the k-means edge quantile).
- **Seeds for tuning:** 100–102 (never the 0–9 reporting seeds).
- **Selection rule:** choose the configuration with the best mean `final_cov` on
  validation layouts. Decide this rule before tuning.
- **Training budget:** `____` timesteps per RL run, the same for every algorithm (or justify
  per-algorithm budgets in Deviations).
